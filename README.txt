# Portfolio Rico Edwardo

Website portfolio modern dan responsive untuk Rico Edwardo.

## Cara menjalankan
1. Extract folder.
2. Buka `index.html` di browser, atau gunakan Live Server di VS Code.
3. Edit isi project, email, WhatsApp, dan foto sesuai kebutuhan.

## Catatan
- Nomor WhatsApp pada tombol masih contoh: `6280000000000`.
- Jika ingin memakai foto sendiri, tambahkan foto ke folder `images` lalu ubah bagian `profile-placeholder` di `index.html`.
- Website ini tidak membutuhkan database karena dibuat dengan HTML, CSS, dan JavaScript.
